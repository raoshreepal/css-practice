# Practical 06: Team Cards

- Company team pages
- Employee directory

- Leadership showcases
- Team member highlighting

## 🎨 CSS Topics
- Circular images (border-radius: 50%)
- Overflow hidden for image masking
- Card hover effects
- Profile information layout
- Responsive card grids
