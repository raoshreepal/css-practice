## 🎨 Common CSS Patterns Used

### **1. Responsive Grid Pattern**
```css
.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 20px;
}

@media (max-width: 768px) { /* Tablet */ }
@media (max-width: 480px) { /* Mobile */ }
```

### **2. Gradient Background**
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### **3. Flexbox Centering**
```css
display: flex;
justify-content: center;
align-items: center;
```

### **4. Card with Hover Effect**
```css
.card {
  box-shadow: 0 4px 15px rgba(0,0,0,0.1);
  transition: all 0.3s;
}
.card:hover {
  transform: translateY(-10px);
  box-shadow: 0 8px 25px rgba(0,0,0,0.15);
}
```

## 📱 Responsive Breakpoints

All practicals include these standard breakpoints:

```css
/* Desktop (Default) */
/* No specific breakpoint */

/* Tablet */
@media (max-width: 768px) {
  /* Adjusted layout and sizing */
}

/* Mobile */
@media (max-width: 480px) {
  /* Optimized for small screens */
}
```

## 🤝 Best Practices

### **Naming Conventions:**
- Use descriptive class names: `.hero-section`, `.card-item`
- Use BEM methodology: `.block__element--modifier`
- Avoid numbers-only classes

### **CSS Organization:**
- Group related styles together
- Use comments to section code
- Maintain consistent indentation
- Keep selectors specific but not overly complex

### **Performance:**
- Minimize use of expensive properties
- Use transitions instead of animations
- Compress images before using
- Remove unused CSS

### **Accessibility:**
- Use semantic HTML
- Ensure sufficient color contrast
- Provide alt text for images
- Use proper heading hierarchy
