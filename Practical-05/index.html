CSS Properties Explained

1. Display Grid/Flex

Purpose: Arranges pricing cards in rows automatically.

Syntax: display: grid; grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));

Real Project Usage: Stripe, GitHub, Figma use grid for pricing.

2. Box Shadow

Purpose: Creates elevation and depth for cards.

Syntax: box-shadow: 0 4px 15px rgba(0, 0, 0, 0.1);

Real Project Usage: All modern pricing pages use shadows.

3. Border Radius

Purpose: Rounds corners of cards for modern look.

Syntax: border-radius: 12px;

Real Project Usage: Standard for all card-based designs.

4. Transform & Scale

Purpose: Creates hover effects to highlight cards.

Syntax: transform: scale(1.05); translateY(-10px);

Real Project Usage: Interactive pricing pages use hover effects.

5. Positioning (Relative/Absolute)

Purpose: Positions badge on card and featured indicator.

Syntax: position: absolute; top: -15px;

Real Project Usage: Badges and badges on pricing cards.

6. Background Gradient

Purpose: Creates visual distinction for featured plan.

Syntax: background: linear-gradient(135deg, color1, color2);

Real Project Usage: Featured cards stand out with gradients.

7. Padding & Margin

Purpose: Creates spacing inside and between cards.

Syntax: padding: 30px; margin: 20px;

Real Project Usage: Professional spacing for readability.

Best Practices for Pricing Pages

  • Do: Make featured plan visually distinct
  • Do: Use consistent spacing between cards
  • Do: Make CTA button obvious (contrast)
  • Do: Show feature differences clearly
  • Do: Use hover effects for interactivity
  • Avoid: Don't crowd too many features
  • Avoid: Don't hide pricing information

Interview Questions

Question 1

How do you create a responsive grid that shows 3 cards on desktop, 2 on tablet, 1 on mobile?

Hint: Use grid-template-columns with auto-fit or auto-fill

Question 2

How do you position a "Most Popular" badge on the top of a card?

Hint: Use position: absolute with negative top value

Question 3

What CSS creates a subtle lift effect on hover without changing layout?

Hint: Use transform: translateY and transition

Question 4

How do you make one card appear "featured" or "highlighted"?

Hint: Use different background, border, or shadow

Question 5

How do you align pricing sections (currency, amount, period) professionally?

Hint: Use display: flex or inline-block with alignment

Student Exercise

Objective: Design a 3-tier pricing page:

Requirements:

  • 3 pricing cards: Basic, Pro (featured), Enterprise

  • Hover effects that lift cards slightly
  • CTA buttons with proper contrast
  • Responsive grid layout
  • Feature list with checkmarks or X marks
